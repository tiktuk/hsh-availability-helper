Einstellungen

Briefkopf, Texte und Unterschrift für die Monatsrechnung, dazu der eigene Kalender für die Wochenansicht. Leere Felder erscheinen nicht auf der Rechnung.

Rechnungssteller

Rechnungsempfänger

Bankverbindung

Texte

Eine Zeile je Aufzählungspunkt. Die Zeile „Ich versichere,“ steht fest darüber.

Unterschrift

PNG oder JPG, wird auf 800 px Breite verkleinert und nur lokal auf diesem Rechner gespeichert (nicht synchronisiert).

Nummernkreis

Jeder Monat behält seine Nummer; auf der Rechnung selbst ist sie änderbar. Dreistellig, z. B. 2026-007.

Kalender (iCal)

Die Adresse ist ein Geheimnis: wer sie kennt, liest den Kalender. Sie bleibt auf diesem Rechner (nicht synchronisiert) und wird nur zum Laden der Termine verwendet. Beim ersten Speichern fragt Chrome nach der Erlaubnis für genau diesen Server.
